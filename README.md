# 정렬 리모컨 — PowerPoint 정렬 추가 기능

- 리본에 **[정렬] 탭**이 생겨요: 왼쪽·가운데·오른쪽 / 위·중간·아래, 가로·세로 간격 분배, 기준 선택, 리모컨 열기
- **[리모컨]** 버튼을 누르면 PowerPoint 오른쪽에 패널이 붙어요 (떼어서 띄워 둘 수도 있어요)

## 기준 3가지

| 기준 | 동작 |
|---|---|
| 선택 영역 | 선택한 오브젝트 전체를 감싸는 영역에 맞춤 (기본) |
| 기준 오브젝트 | **처음 선택한 오브젝트**는 고정, 나머지를 거기에 맞춤 (일러스트레이터 키 오브젝트) |
| 슬라이드 | 슬라이드에 맞춤. 오브젝트를 1개만 선택하면 자동으로 슬라이드 기준 |

- 리모컨의 **선택 순서** 목록에서 원하는 오브젝트를 누르면 그게 ★기준이 돼요.
- Shift/⌘ 클릭으로 하나씩 고르면 순서가 정확히 잡혀요. 드래그로 한 번에 묶어 고르면 순서가 PowerPoint 내부 순서가 되니, 목록에서 기준을 한 번 눌러 주세요.

## 간격

- **가로 / 세로** 버튼: 양 끝은 그대로, 사이 간격을 똑같이 (3개 이상)
- 버튼 아래 두 칸은 **지금 간격**을 보여줘요 (2개 이상 선택 시). 값을 바꾸고 Enter → 그 간격으로 붙여요.
  - 기준 오브젝트 모드면 ★오브젝트 위치 고정, 아니면 맨 왼쪽/맨 위 오브젝트 고정
  - 간격이 제각각이면 칸이 비어 있어요.

## 모양

- **X / Y**: 슬라이드 왼쪽 위에서의 위치. 여러 개면 선택 전체를 한 덩어리로 옮겨요.
- **가로·세로 크기**: 값 입력 후 Enter. 가운데 고리 버튼을 켜면 가로세로 비율 고정
- **회전**: 각도 입력 또는 오른쪽 목록에서 선택
- **라운드 조절**(접기/펴기): 둥근 사각형처럼 모서리 조절점이 있는 도형을 고르면 칸이 활성화돼요. 넣을 수 없는 도형이면 입력 불가
- 여러 개 선택 시 값이 다르면 "여러 값"으로 보이고, 입력하면 모두 그 값이 돼요.
- 단위는 맨 위 선택 칸(cm/mm/pt/px)으로 바꿔요.

## 단축키

리모컨 맨 아래 **단축키**를 펴면 설정할 수 있어요.

- 기본: 왼쪽 ⌘⌥1 · 가로 가운데 ⌘⌥2 · 오른쪽 ⌘⌥3 · 세로 가운데 ⌘⌥4 · 위 ⌘⌥5 · 아래 ⌘⌥6
- **단축키 설정** → 원하는 조합 누르기 → **확인**
- **단축키 사용** 스위치로 전체 켜기/끄기

## 설치 (Mac, 최초 1회)

Office 추가 기능은 https 주소에 올려 둔 파일을 불러오는 방식이라, 파일을 한 번 웹에 올려야 해요. GitHub Pages(무료)로 하면 돼요.

1. [github.com](https://github.com) 가입/로그인 → 오른쪽 위 **+ → New repository**
   - 이름: `ppt-align-remote`, **Public** 선택 → Create
2. 저장소 화면에서 **uploading an existing file** 클릭 → 이 폴더의 파일을 전부 끌어다 놓기
   (`assets` 폴더째로) → **Commit changes**
3. 저장소 **Settings → Pages** → Branch를 `main` / `(root)`로 두고 **Save**
   1~2분 뒤 `https://아이디.github.io/ppt-align-remote` 주소가 생겨요.
   브라우저로 `…/taskpane.html`을 열어 미리보기 화면이 뜨면 성공.
4. 이 폴더의 **`setup-mac.command`를 우클릭 → 열기** → 3번 주소 붙여넣기 → Enter
5. PowerPoint를 **⌘Q로 완전히 종료** 후 다시 실행
   → **홈 탭 → 추가 기능(Add-ins)** → 목록에서 **정렬 리모컨** 선택
   → 리본에 **[정렬] 탭**이 생겨요.

> 처음 한 번 보안 경고가 뜨면 "허용"을 누르세요.
> Windows PC나 웹 PowerPoint에서도 같은 `manifest.xml`(주소만 바꾼 것)로 쓸 수 있어요.

## 알아두면 좋은 점

- 회전된 오브젝트는 회전 전 상자 기준으로 계산돼요.
- 크기 변경은 왼쪽 위 모서리를 기준으로 늘고 줄어요.
- 회전·라운드는 최신 PowerPoint(API 1.10 이상)에서만 동작해요.
- 슬라이드 크기는 자동 감지하고, 안 되면 리모컨 하단 **슬라이드 크기**에서 16:9 / 4:3 / 직접 입력을 고를 수 있어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.xml` | PowerPoint에 등록하는 설정 (리본 탭, 버튼) |
| `taskpane.html` / `taskpane.js` | 리모컨 패널 + PowerPoint 연동 |
| `align-core.js` | 정렬·분배 계산 |
| `shortcuts.json` | 기본 단축키 |
| `assets/` | 리본 아이콘 |
| `setup-mac.command` | Mac 설치 스크립트 |
